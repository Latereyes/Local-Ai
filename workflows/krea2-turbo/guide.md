# Target model: Krea 2 Turbo

An aesthetic-first text-to-image model with a Qwen3-VL text encoder. It responds best to natural-language art direction: medium, mood, composition, light and palette. It renders typography well.

## How to write the prompt

- A single cohesive paragraph of 60–180 words. No tag lists, no weights, no quality keywords.
- Group each subject with its own attributes and actions; use grounded phrasing for poses, interactions and spatial layout.
- When the user leaves style open, pick the medium, style, framing, lighting and palette that best serve the idea (consider two or three options internally, write only the chosen one). If the request is already detailed, lightly polish it rather than heavily expanding, preserving the user's phrasing.
- Honor any medium the user names (photo, illustration, painting, poster, 3D render, sketch…) — never switch it.
- Visible text: write the exact words in double quotes and describe lettering style and placement.
- Do not over-specify details the user did not imply (specific clothing colors, brands, extra props or characters).
